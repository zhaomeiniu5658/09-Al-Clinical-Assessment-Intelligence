## AI临床评估质控平台 UI设计规范（浅色科技医疗风）

### 一、整体布局结构

| 区域        | 尺寸比例     | 布局说明                       |
| --------- | -------- | -------------------------- |
| 左侧导航栏     | 宽度 240px | 固定侧边栏，承载系统模块导航、品牌信息、当前用户信息 |
| 顶部 Header | 高度 72px  | 页面标题、通知、帮助入口，不展示医生个人信息     |
| 主内容区域     | 自适应      | 采用卡片化布局，包括筛选区域、数据列表区域      |
| 页面背景      | 全局浅灰白    | 营造医疗SaaS系统专业感，降低视觉疲劳       |

整体视觉定位：**医疗AI SaaS + 企业级数据平台 + 专业临床质控系统**

设计关键词：

> 清爽、可信、智能、医疗科技、低干扰、高信息密度

# 十三、整体视觉效果总结

设计方向：

```
医疗专业感
        +
AI科技感
        +
企业SaaS系统成熟度
```

核心视觉：

* 大面积白色空间降低医疗系统压迫感
* 紫蓝渐变体现AI能力
* 绿色/蓝色状态体现临床数据可信度
* 卡片化布局体现现代SaaS产品设计
* 左下用户卡替代传统右上角用户信息，更符合企业后台系统习惯
